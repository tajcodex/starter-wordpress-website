# StarTer – WordPress Website
A modern and responsive WordPress website designed with Elementor and the Phlox theme.

## 📸 Website Preview
![StarTer Website Preview](starter-homepage.png)

##  Project Overview
StarTer is a modern website concept focused on clean design, responsive layouts, and a user-friendly browsing experience.
The website was designed and developed as a WordPress practice project.

##  Features
- Modern and clean UI design
- Fully responsive layout
- Elementor-based page design
- Responsive navigation menu
- Hero section with call-to-action
- Services section
- Professional website layout
- Hover effects and animations
- Mobile and tablet friendly design

##  Technologies Used
- WordPress
- Elementor
- Phlox Theme
- HTML
- CSS
- JavaScript

##  Project Status
Completed as a WordPress development practice project.
